# Responsive HTML Email

A responsive marketing email template built with HTML and CSS, with a focus on email-client compatibility, mobile responsiveness, and reliable rendering.

## Live Demo

[View the responsive HTML email demo](https://yjxca.github.io/responsive-html-email/)

## Features

- Table-based email layout
- 600px desktop email container
- Responsive mobile layout
- Two-column layout that stacks on smaller screens
- Inline CSS for email-client compatibility
- Hidden preheader text
- CTA button built with email-safe markup
- Microsoft Outlook conditional comments
- Mobile typography and spacing adjustments

## Technologies

- HTML5
- CSS3
- Media Queries
- Email-safe table layouts
- MSO conditional comments

## Responsive Behavior

### Desktop
The feature section displays in two columns.

### Mobile
At screen widths below 600px:
- Columns stack vertically
- Heading size is reduced
- Horizontal padding is reduced
- The email container adapts to the available screen width

## Purpose

This project was created as a portfolio demonstration of responsive HTML email development, including techniques commonly used to improve compatibility across email clients such as Outlook, Gmail, and mobile email applications.
